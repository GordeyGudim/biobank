   записями не из Excel без `--force`; вынести проверку в `importer.import_guard` (позже заменена сравнением баз, п. 8).
3. ✓ `identify` принимает вид при уверенности «не определён» — запретить (`edit.py:230`).
4. ✓ Гонка «проверка → запись» в `resolve_issue`, `link_trawl`, `identify`:

5. ✓ `run_checks`: добавить `table_name`, `record_id` в ключ проблемы, не сворачивать записи
   без листа Excel (`checks.py:191-279`).
6. ✓ CLI: ловить `sqlite3.Error` наравне с `EditError` (`__main__.py:195`); источник
   резервной копии открывать только на чтение (`edit.py:58`).
7. ✓ Мелочи импорта: проблема «ХХ» может привязаться к чужой особи (`importer.py:736`);
